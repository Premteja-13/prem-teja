How to configure your Gemini API Key:

For security, API keys are stored on the server in .env and never exposed in browser code:

  1. Obtain a free key from Google AI Studio.
  2. Open the project root file .env.
  3. Add your key: GEMINI_API_KEY=your_key_here.
  4. Save the file. The server automatically reads the key for all analyses.
